
## Vision

Flisk should become the most reliable, developer-friendly local development platform for modern multi-service applications and AI-assisted engineering teams. Its focus should be making any existing application easy to run, inspect and develop locally through one consistent interface, while enabling coding agents to work independently and safely.

## Not now

Flisk should not become a production deployment or Kubernetes orchestration platform yet. Its strongest differentiation is simplifying local development and AI-assisted application engineering. Expanding into production infrastructure would increase operational complexity and distract engineering effort from improving the core developer experience.
